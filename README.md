# Arcade Signal Degrader
A bitcrusher plugin built with JUCE, documented step-by-step as I learn digital signal processing. 

This project is both: 
- An in-progress, functional bitcrusher audio effect.
- A growing set of DSP tutorials written from a beginner-intermediate perspective.

### Background
I come from a background in cognitive science and auditory perception, focusing on modeling sound quality in hearing aids. This project is part of my transition into electrical and computer engineering, bridging my theoretical knowledge with hands-on DSP.

### What it is
- Quantization (bit reduction)
- Downsampling
- Low-pass filtering
- Additional controls for artifacts and sound destruction
- Dry and wet mix control
- Input and output gain control with dB scaling

### Work in progress
This project is currently focused on documenting DSP concepts and development progress. Plugin release timeline will be announced as it nears completion.

### Cloneable, open-source DSP modules
While the full plugin is in development, small, cloneable DSP modules will be provided. Each module will focus on a single topic and can be run independently. The purpose of these modules is to keep individual DSP topics testable and easy to understand.

### Why this exists
DSP tutorials can be overwhelming and don't always seem immediately intuitive. This project focuses on practical understanding and learning by building.
